# PhotoVault

PhotoVault 是一个原生 SwiftUI + PhotoKit 的 iOS / iPadOS 相册。

## 已实现

- 图库与系统智能相册、自定义相册浏览
- 按当前相册播放幻灯片，支持暂停、手动翻页和沉浸式显示
- “未整理”视图：排除所有自定义相册后显示未加入相册的照片
- 选择照片后添加到已有相册或新建相册、系统分享、删除
- 全屏查看、双击/双指缩放、收藏、照片信息
- 详情页相册快捷栏：左右翻照片时常驻，一点加入相册并显示勾选与 +1；支持已加入、最近、全部、星标筛选，搜索、排序和新建相册
- iCloud 照片的网络读取
- 搜索相册名称，以及照片、视频、收藏和四位年份等公开元数据

## 录屏功能工作区（1.1.1）

- 图库：年、月、日、日记、展开、紧凑六种浏览方式，月份日历可直接打开当天；照片、视频、收藏、截屏、Live Photo 筛选与时间排序。
- 编辑：自由裁剪及常用比例、左右旋转、镜像、0.1° 调平、滤镜、自动调整、14 项参数、保存自定义效果、撤销/重做及按住看原图。
- 压缩：JPEG / HEIC / PNG、画质预设与滑杆、480p 至 4K 和原分辨率、实际导出体积与尺寸、另存/可还原覆盖；视频使用系统编码器并保留声音。
- 对比：持久化压缩记录、原文件/结果并排查看或播放、删除原文件/结果、还原覆盖编辑。
- 清理：本机文件体积扫描、字节相同与相似照片、大照片/视频/截图/Live Photo、体积排序、每日占用与尺寸分布、相册整理、随机日期、空相册和空文件夹。
- 相册：全部、星标、历史、共享，文件夹层级、搜索、创建、排序及列表/卡片切换；详情页常驻快捷相册栏。
- 发现：长截图（多图按序拼接、自动/手动接缝、顶部/底部裁切、PNG 保存和分享）、随机漫游、往年今日、收藏、照片备注、日记、生日和纪念日、日记导出、文字识别/复制/翻译。
- 地图：按拍摄位置聚合，点击地点打开对应照片。
- 设置：系统/浅色/深色、权限入口、日记导出、图片缓存清理，以及原有启动页、应用图标和播放设置。

压缩另存保留拍摄日期、位置、收藏、相册及应用内备注。覆盖使用 PhotoKit 可还原编辑，系统仍保留原片；要释放空间可在对比页确认删除原文件。Live Photo 使用系统动态编辑，保留照片/视频配对，画质和分辨率由系统管理。清理扫描不自动下载 iCloud 原片；未下载项不计入已测体积，Live Photo 的体积只统计本机静态资源。

功能与验证记录见 [录屏实现清单](docs/reference-workflows.md)。

## 性能策略

- 列表使用 `PHFetchResult<PHAsset>`，不把 10 万张照片转成 `[PHAsset]`
- 网格使用可回收的 `UICollectionView`，未整理视图按元数据页加载
- 使用 `PHCachingImageManager` 做缩略图缓存和预热
- 相册元数据在后台读取；“未整理”索引只在进入该页面时建立，并在后台建立资产 ID 集合
- 全屏查看和幻灯片只保留当前照片附近的页面，避免为整个图库创建视图
- 统一请求调度器区分查看器、幻灯片、可见网格和远端预取；后台时收敛低优先级工作
- Debug 构建提供图库、索引和活动媒体请求面板

## 运行

用 Xcode 打开 `PhotoVault.xcodeproj`，选择 iPhone 或 iPad 模拟器/真机运行。部署目标为 iOS/iPadOS 26.0，首次运行需要允许照片访问。

开发约束、性能注意事项、详情分页手势和真机验证中的踩坑记录见 [`AGENTS.md`](AGENTS.md)。

详情页默认显示相册快捷栏。点底部相册按钮或快捷栏右上角的关闭按钮可收起，恢复照片胶片条；再次点相册按钮可展开。长按相册缩略图可设为星标或移出该相册，长按底部相册按钮可打开完整相册选择器。最近使用的相册、星标及快捷栏显示状态会跨启动保存。
