# PhotoVault 整体审查与修复（1.1.2）

审查当前主分支，并以 `54478ae...9ead973` 检查录屏工作区的新增路径。规范审查覆盖 PhotoKit、SQLite 索引、图片请求、详情分页/退出和文件夹模块；功能审查覆盖编辑、压缩、时间线、发现、清理和地图。这里只记录有具体触发条件的问题，不把纯风格偏好当缺陷。

## Standards：规范与核心可靠性

| 级别 | 问题与触发条件 | 修复 |
| --- | --- | --- |
| P1 | 智能搜索全量扫描吞掉 SQLite 批次写入错误，仍提交 token，失败批次永久遗漏 | 分批写入传播错误，全部写入和对账成功后才提交 token |
| P1 | 扫描结束才读当前 token，会跳过扫描/增量处理期间的新变化 | 全扫先捕获边界 token；增量只保存已应用变更的 token；普通数据库错误不触发全扫 |
| P1 | token 过期后全扫只 upsert，保留已经删除的旧资产、向量与 OCR | 完整扫描后按 ID 分页对账，沿用既有向量释放和 OCR 清理逻辑 |
| P2 | 详情页“从照片库删除”成功后仍留在已删除照片的旧快照 | 增加真实删除成功回调，两种详情页通过既有关闭入口退出；系统取消仍静默保留页面 |
| P2 | 慢拖提交阈值实际为 6%，与项目约定的 30% 不一致 | 恢复 30%，保留快速甩动每次一页 |
| P2 | Core Image 会把小数裁剪边界向外取整，导出带透明/黑色边缘 | 在裁剪时对齐内部有效像素；缩放使用明确整数尺寸及边缘扩展 |
| P2 | 快速旋转后立即选择裁剪比例，会读取尚未更新的异步预览尺寸 | 比例由稳定原图尺寸与当前旋转配方计算 |

## Spec：录屏功能和操作一致性

| 级别 | 问题与触发条件 | 修复 |
| --- | --- | --- |
| P1 | 更改压缩设置后渲染失败，会重新启用上一次结果，可能与当前格式不符 | 结果按配方/选项绑定，切换即失效，预览和结果完成后一起发布，保存再次校验 |
| P2 | 视频导出期间仍可更改分辨率，最终结果与选择状态不一致 | 导出前捕获选项，处理中锁定选择器并防重复调用 |
| P2 | 还原原片后，压缩历史仍显示旧体积和“可还原编辑” | 成功还原后移除该资产的覆盖编辑记录并持久化 |
| P1 | 视频/收藏等筛选的时间线点进月份或某天后混入全库媒体 | 日期下钻与月份日历携带筛选范围、排序；查询合并日期和媒体条件 |
| P2 | 日记模式漏掉没有照片的日记日期 | 日记日期合并到日期分组，支持空照片日期 |
| P2 | 同一 fetch 身份下的日期修改不能刷新时间线 | 时间线任务跟随图库 revision 和日记日期更新 |
| P1 | 暂停扫描、后台或离开页面会把部分扫描覆盖为完整缓存 | 取消传播到扫描任务，保留上次完整快照，不发布未完成结果 |
| P2 | 相似照片只比较最近 100 张，跨窗口候选遗漏 | 六段哈希分桶跨图库找候选，避免全量两两比较 |
| P2 | “重复文件”未包含本机视频 | 对本机视频同样流式计算摘要；旧缓存升级后重新扫描 |
| P2 | 每日统计把云端未知大小显示为 0 B | 单列未知数量，全部未知时显示“大小未知” |
| P2 | 随机整理在图库尚未加载时执行一次后永久显示空库 | 随图库 revision 重试，并保留仍有效的当前日期 |
| P2 | 紧凑/展开只写偏好，当前 UICollectionView 尺寸不变 | 模式操作同步到布局，同时保留捏合尺寸持久化 |

## 验证与限制

- SQLite 真实存储测试：83 项通过；新增跨 1,205 行/多个分页的元数据、向量、OCR 清理及幂等对账用例。
- iOS 模拟器图像与工作区探针：58 项通过，包含小数裁剪透明像素、格式与元数据、无照片日记、跨窗口相似图、未知大小及扫描取消保护。
- 相似索引合成基准：100,002 条哈希约 0.10 秒，进程峰值约 85 MB；这是本机哈希检索基准，不包含 PhotoKit 读取、文件摘要和 iCloud 下载。
- 19 个模拟器 UI 回归用例全部通过（0 失败，约 481 秒）。用例固定与自身目标相关的启动状态，避免上一次时间线模式影响详情回归；覆盖真实删除确认与取消、筛选下钻、模式切换、慢拖回弹、压缩保存/还原、详情退出和幻灯片自动推进。
- 发布包采用 Apple Distribution 签名与有效 App Store 描述文件；GitHub IPA 导出不代表上传 TestFlight。
- 大图库与 iCloud、Live Photo 动态编辑、SMB/NAS 和真机转场打断仍需有相应数据及设备的人工验收；模拟器通过不等同于这些环境已验收。
