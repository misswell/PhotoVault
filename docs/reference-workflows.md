## 数据与性能边界

- 全库仍是 `PHFetchResult`，网格、详情、胶片条仍使用原有可回收 UIKit 组件。时间线、GPS 聚合、大小扫描、重复检测和图像处理在后台执行。
- 预览/导出使用同一套 Core Image 配方；ImageIO 写入正确方向及 EXIF/GPS 日期。不会把低分辨率文件放大。
- 清理扫描只读本机已有资源，不自动下载 iCloud 原片，界面注明已测项目/总项目。Live Photo 体积是本机静态资源体积，相似匹配是建议，删除仍使用系统确认。
- Live Photo 使用系统可还原动态编辑保留配对。系统管理画质和分辨率，界面不会把静态预览体积标成整个 Live Photo 的压缩结果。
- PhotoKit 覆盖属于可还原编辑，系统仍保留原片，不宣称已释放原片空间；压缩另存后可在对比页删除原文件。
- 备注、日记、生日、效果与压缩记录保存在本机应用数据中，日记可以导出。
- GitHub IPA 使用 Apple Distribution 签名及 App Store 描述文件，是 App Store Connect 发行包；不能作为任意设备侧载包，生成 IPA 不等同于上传 TestFlight。

## 验证

`ReferenceWorkflowUITests` 验证图像几何与格式/元数据、编辑撤销、真实另存与对比、覆盖后还原、视频压缩、六种浏览模式、备注保存与搜索、本机扫描和地图入口。`PhotoEditProbe` 在 DEBUG 下用固定图验证旋转/裁剪/调平/不放大、全部滤镜/参数、JPEG/HEIC/PNG 的日期与 GPS、配方序列化及闰日纪念日。

现有详情回归覆盖关闭、下拉、取消后再下拉、翻页后返回、整个视口命中、未整理详情返回、相册快捷栏、收藏与幻灯片自动推进。输入通过 XCUITest 完成，关键页面保留截图附件。

测试环境：Xcode 26.6，iPhone 17 Pro / iOS 26.5 模拟器，包含带日期/GPS 的照片、重复文件和视频种子。已连接真机显示 unavailable；真机的交互中断压测、iCloud 大图库，以及实际 Live Photo 动态结果仍需要设备可用后人工验收，模拟器通过不能替代这部分结论。

最终验证结果（2026-10-04）：16 个不同的关键 UI 场景完成验证。原有 8 项详情/快捷相册/幻灯片回归通过；视口命中用例按当前布局取样后通过；新增 7 项工作区流程通过，其中另存、覆盖还原、视频导出/尺寸/播放对比在最终候选构建中单独复验。Release 归档、手动发行签名和 IPA 导出成功，已核对 1.1.1 / build 37、iOS 26.0 部署目标、完整 AI 模型资源与 SHA-256。
