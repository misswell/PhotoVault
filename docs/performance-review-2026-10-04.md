# 1.1.3 交互与流畅度审查

审查基准：`620303b75bb424d540760c2462085fd576823b61`（1.1.2）。需求：详情页简化、地图减少卡顿、清理图标补齐，并检查分页、图片加载和列表更新的流畅度。

## Standards

- 清理、时间线和发现列表曾在 SwiftUI 求值期间同步解析资产。改为后台 actor 查询、可见行任务和清理当前页批量解析，导航目标同样延迟查询。备注搜索增加 180ms 防抖和每次 200 条结果；相册异步查询复用已有缓存。
- 编辑、压缩和对比的 UIImage 首次解码与大文件写入移到 `PhotoRenderWorker`；返回主线程之前检查取消与当前配方，旧结果不能覆盖新预览。
- 当前页的队列优先级原先会沿用初次加载时的邻页身份。现在随当前索引调整等待队列，按 pager owner 隔离，不取消和重启已在执行的 PhotoKit 下载。
- 后台取消会让未完成的可见请求没有恢复入口，内存警告还会清空可见 cell。补齐前台恢复与请求代次校验，保留可见帧和可见下载，预取拥有者在缓存清理后释放失效的记录。网格按是否收到最终帧判断恢复：低清帧保留原位并重新请求，已完成的缩略图直接复用；请求回调带代次守卫，旧低清帧不能覆盖新最终帧。恢复仅发生于真实后台返回。
- 未引入新的转场相位、轮询或延迟恢复。前后台测试曾失败，但诊断显示 hosting view 已启用，推测性的交互恢复代码已撤回；测试改为等待前台并重新查询坐标。

## Spec

- 两套详情页统一为五个常用按钮：编辑、收藏、相册、分享、更多。幻灯片和回收站移入更多，保留全部功能；相册快捷栏默认收起，支持手动展开并保存选择。
- 地图移除每个标注上的 SwiftUI 图片树，使用可回收原生标记与聚类，最多 400 个元数据标注。相机变化只操作 MapKit；只有选中地点显示照片预览，地点下钻捕获匹配的照片快照，避免图库更新时索引串位。
- 清理标签和空相册入口采用目标系统已验证的 SF Symbols，清理列表明确使用标题与图标样式。运行时探针验证相关图标可创建；没有把旧名称的有效性推测当作已证实根因。

## 验证与边界

验证记录在 `build/review-1.1.3`，包含 UI 结果包、截图、签名归档和导出日志。地图回归检查拖动/缩放及切换标签前后的标注更新计数保持一致；详情回归检查五个按钮的命中宽度、默认快捷栏状态、翻页、退出和前后台恢复。

27 个不同关键场景分批验证通过：`ValidatedReview.xcresult` 的 25 项中 22 项通过，3 项暴露测试前提问题（视频被当作照片缩放、前台窗口坐标复用、未整理幻灯片入口未固定网格模式）；修正后 `FinalRegressions.xcresult` 的 4 项全部通过，包含这 3 项及加强后的地图标记→地点网格流程。图标与图像处理运行时探针另有独立通过记录 `Symbols.xcresult`。build 40 的 `Build40Regressions.xcresult` 另有 4 项全部通过，覆盖模拟低清帧前后台恢复、详情前后台翻页和两套网格退出命中。build 41 的 6 项回归在日志中全部通过，但结果包收尾阻塞，已停止该测试进程；最终源码通过有效的 `FinalCandidate.xcresult` 再验证 3 项（照片缩放、低清缓存回网格刷新、低清帧前后台恢复）。最终 build 41 加强低清缓存与恢复覆盖：缓存保存帧质量，低清命中继续请求高清；同一照片保留最终帧时不接受降级回调。低清用例使用 DEBUG 故障注入，验证保帧、缓存质量与重发路径；它不代表真实 iCloud 网络测试。未把最初失败的完整测试结果包标成通过。

Release 归档与 IPA 导出成功，`codesign --verify --deep --strict` 通过；核对版本 1.1.3 / build 41、最低系统 26.0、两个 SigLIP2 模型与 tokenizer 均完整。产物在 `build/releases/1.1.3/PhotoVault.ipa`，配套 `SHA256SUMS`。

模拟器：iPhone 17 Pro / iOS 26.5，包含 GPS 照片、重复文件和真实视频/导出结果。缩放用例曾点开最新导出的视频，因此先筛选照片后再验证，避免测试数据造成假失败。

这些验证不构成真机帧率测量，也不能替代十万照片、iCloud 网络波动或转场中途连续手势的人工压测。已经开始的同步 PhotoKit 查询无法强制中断；取消检查能跳过尚未开始的查询并阻止过期结果发布。
